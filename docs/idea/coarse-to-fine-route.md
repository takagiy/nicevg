# 粗い格子で通り道を決めてから、その中だけ細かく探す

## きっかけ

融資審査 DFD を 1 回 fix したときの探索 138 回を書き出して比べると、ほかのコネクタが 0 本の探索は格子 72×112 で 260〜690 状態しか訪れないのに、約 40 本ある探索は格子 109×198 で 5000〜18000 状態を訪れていた。格子は 2.7 倍にしかならないのに、訪れる状態は約 25 倍になる。

格子の線は障害物の縁・端点・ほかのコネクタが走る線から引かれ、どれも図の端から端まで伸びる。混んだ所では交差（300）や並走（120）を払うより遠回りが安くなるが、推定（docs/idea/tighter-route-heuristic.md）は遠回りが要る状態でこれらを数えないので、A* はその値段に届くまで広い範囲を展開する。

## 案

1. 粗い格子: ほかのコネクタや rail が走る線を引かず、障害物の縁と端点の線だけで格子を作る。交差・並走・ニアミスの値段は細かい格子と同じく、ほかのコネクタから付ける。この格子で A* を走らせ、大まかな経路を得る。
2. 通り道: 粗い経路の各区間を、粗い格子でその両隣の線まで広げた長方形の和とする。区間が通る通路と、その縁の障害物までが入る。
3. 細かい格子: 今と同じ格子と値段で、通り道の中の点だけを通って A* を走らせる。見つからなければ、通り道なしで探し直す。

## どの段階で使うか

- 辺の選択（`choose_sides`）と本番の経路（`route_connector`）の両方が `search` を通るので、まず `search` の中で 1→3 を行う。
- 辺の選択は、粗い経路の端だけで足りるかもしれない。細かい探索を省けるかは、上の結果を測ってから決める。
- arrange の候補の評価は fix を通るので、そのまま速くなる。粗い値段だけで候補を絞るのは、選ばれる移動が変わりやすいので後回しにする。
- 並走の間隔は、最後の `spread_close_runs` が広げる。

## 気をつけること

- どちら回りに迂回するかは粗い経路で決まり、細かい探索では変えられない。粗い格子では並走が起きにくいので、混んだ通路を選んで、細かい探索で並走を払うことがありうる。そうなるなら、通路の混み具合を粗い値段に入れる。
- 出力は変わる。変わった箇所は前後の画像で確かめてもらう。

## 測ること

- 探索ごとの経路の値段: 全体を細かく探したときとの差（悪化の頻度と大きさ）。
- 訪れる状態の数と時間: 粗い探索と細かい探索の和を、今の 1 回と比べる。
- 通り道で見つからず、全体で探し直した回数。

## 結果（2026-10-12、融資審査 DFD の arrange、探索ごとに全体の細かい探索と比べた）

訪れる状態の数（1 回の平均）と、値段が全体の探索より 120 を超えて高くなった探索の割合:

| 粗い格子・通り道 | 辺の選択 | 本番の経路 |
|---|---|---|
| 全体を細かく（今まで） | 2314〜3429 | 7886〜8442 |
| コネクタの線だけ抜く | 2579（0.9%） | 5833（5.7%） |
| ＋ チャネル中央の線も抜く | 1280（0.9%） | 3400（5.7%） |
| ＋ 細かい格子を通り道の範囲だけで作る | 870（1.8%） | 2640（4.5%） |
| 通り道を囲む長方形を 100px 広げる | 2104（0.3%） | 6575（2.8%） |

- コネクタの線を抜くだけでは格子はあまり粗くならない（142×248 → 127×190）。線の多くは障害物（ノードとラベル）の縁と、その間のチャネル中央から来る。中央の線も抜くと、訪れる状態は格子の点の数にほぼ比例して減った。
- 粗い探索の推定を重くする（重み 2・3）と粗い探索は減るが、悪化が 17〜36% に増えた。粗い格子で並走やニアミスを数えない、ほかのコネクタが乗る辺を通れるようにする、も悪化が増えた。
- 通り道を広げても、本番の経路の悪化は数 % 残る。最適な経路が粗い経路から離れた所を回ることがあるため。悪化は粗い経路の通り方（どちら回りか）で決まり、通り道の幅ではあまり変わらない。
- 本番の経路にも使うと、要件テスト 2 件（storefront の f10 の曲がり、融資審査の f20 と f26 の交差）が落ちた。

採った形: 辺の選択（`choose_sides`）だけを粗い経路＋通り道の範囲の細かい格子で探し、本番の経路は今までどおり全体を細かく探す。辺の選択は、経路の値段が多少高くても、選ぶ辺が同じなら結果は変わらない。

| 入力（arrange） | 前 | 後 |
|---|---|---|
| 融資審査 DFD | 10.9 s | 7.9 s |
| 注文 DFD | 1.96 s | 1.56 s |
| ストアフロント | 1.72 s | 1.28 s |
| C4 | 3.04 s | 2.88 s |

融資審査・注文・ストアフロントの出力は変わらず、C4 だけが変わった（曲がり 24 → 23、並走の密度 17.96 → 15.88）。
