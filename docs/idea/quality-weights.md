# 品質指標の重みを、人が見比べた判断から決める

## きっかけ

品質スナップショットに、ジョグ・短い端・交差・角に寄った端子・遠回りなどの指標を足した。指標が増えると、ある変化が改善か後退かを指標ごとに読むのが難しい。人の直感に沿った重みで 1 つの値に合算したい。

## 案

同じ図の経路を 2 通りに崩した A と B を並べ、どちらが悪く見えるかを 6 段階（A が悪い／どちらかといえば A／ほぼ差はないが A／ほぼ差はないが B／どちらかといえば B／B が悪い）で答えてもらう。各版の指標が元の図からどれだけ増えたかの差を説明変数にし、回答に合う重みを当てはめる。

## 1 回目: 手で作った悪化（32 問）

ストアフロントの図に、段差・短い端・迂回・角寄り・並走・ラベルのずれを手で 1 つずつ加えた 16 版で 32 問を作った。同じ種類の中の大小（段差が短いほど悪い、など）はどれも直感どおりだったが、次の理由で重みは決めきれなかった。

- 手で作った悪化は、nicevg が実際には引かない形（何もないところへの四角い迂回など）が多く、現実味に欠けた。
- 交差・曲がり・遠回りがいつも同時に増え、どれが効いたのかを分けられなかった。

## 2 回目: nicevg が実際に引きうる崩れ（本編 128 問 ＋ 追加 64 問）

問題と回答は data/ratings/realistic2-128 にある。

### 版の作り方

- 経路: 線の途中に見えない障害物を置き、fix で避けて引き直させてから障害物を除く。経路探索が実際に引く迂回・交差・ノード際の折れ・並走が残る。
- 端子: 端を辺に沿ってずらす。ほぼ一直線の線の小さな段差（ジョグ）と、角に寄った端子（角から 8px・14px）になる。どちらも過去に実際に出た回帰と同じ形。
- 4 つの例の図（ストアフロント、注文 DFD、C4、融資審査 DFD）を使った。
- 実際には残らない崩れは捨てた: 元の図にない問題を検査で出すもの、表示範囲が変わるもの、ノードが動くもの、斜めの線や 8px 未満の端（経路探索の最短の端より短い）があるもの、変わる線が 4 本以上のもの。ラベルを動かした版は、問題を出さないものでは指標が変わらず、すべて捨てた。
- 指標の上で互いに離れた版を図ごとに 21 版選んで本編の 128 問を組み、どの版も 2〜4 回出るようにした。

### 追加問題

本編のあと、ページがそれまでの回答に重みをリッジ回帰で当てはめ、8 問ずつ追加した（全 64 問）。8 問のうち 6 問は、重みの分散が大きく予測が 0 に近い組（1 組ごとに分散を更新して方向を散らす）、2 問は予測と最も食い違った回答の組を左右を入れ替えて聞き直したもの。候補には本編に出ない 240 版も使った。

### 結果（2026-10-13、回答者 1 人）

- 聞き直した 16 問のうち 14 問が前と同じ側だった。人の判断のぶれはおよそ 1 割。
- 指標の差に、0 以上の重みを、弱いリッジ付きの最小二乗で当てはめた。回答の向きは、当てはめに使った問題で 83%、8 分割で外した問題で 81% 当たる。丸めた重みでは 84%。1 回目の 32 問（手で作った悪化）でも 72% 当たる。
- 1 段階 = 100 点とした重みと、300 回の再標本化での 90% の幅:

| 指標 | 重み | 90% の幅 |
|---|---|---|
| ジョグ 1 つ | 120 | 63〜170 |
| ジョグの段差の 20px への不足（px） | 9 | 5〜13 |
| 3 つ目以降の曲がり | 60 | 40〜67 |
| 曲がったコネクタ | 60 | 18〜76 |
| 交差 | 46 | 28〜56 |
| 並走している線との交差 | 8 | 0〜35 |
| 端の近くの交差 | 7 | 0〜71 |
| 角寄り（px） | 4 | 3〜6 |
| 短い端の 20px への不足（px） | 3 | 0〜5 |
| 並走密度 | 1 | 0.1〜1.8 |
| 遠回り（px） | 0.16 | 0.09〜0.23 |
| 曲がり（2 つ目まで） | 0 | 0〜20 |
| 短い端の数 | 0 | 0〜15 |

- 気にされたのは、ジョグ、3 つ目以降の曲がりとまっすぐだった線が曲がること、交差。遠回りの長さと 2 つ目までの曲がりはほとんど気にされなかった。

この重みで、品質スナップショットに `badness`（点）を足した（`tests/support/mod.rs` の `BADNESS_WEIGHTS`）。問題、斜めの線、離れたラベルは比べておらず、別の項目のまま。

## 残っていること

- 回答者は 1 人。並走している線との交差と端の近くの交差の重みは幅が広く、効くかどうかがはっきりしない。
- ラベルの置き場所の良し悪しを測る指標がない。ラベルを比べるには先に指標が要る。
- arrange の採点（`Context::score`）は、迂回の長さと曲がりの数を重く、ジョグを軽く見ていて、この結果とは逆向き。採点に寄せると出力が変わるので、画像で確かめながら別に進める。
