# 学習データに `--grow` で生成した図を足し、描き方を図ごとにばらつかせる

## 状況

最初の学習用の図（記録 v3）は、生成器が型どおりに作った図、BPMAI、SchemaPile だった（docs/adr/learning-data-sources.md）。エージェントが描く下書きに一番近い例（リポジトリの 6 図）では、ふるい分けの成績が v3 のテスト用の図より低かった（上位 16 件に本来の手が入る割合で 58.3% と 72.0%）。

そこで生成器に `--grow` を足した。数個のノードから始めて、手順を 2 つに分ける、判断で分岐させる、ストアを足す、といった書き換えを重ねて図を作る。図ごとに、どの書き換えをどれだけ選ぶか、つながりの多い部分と少ない部分のどちらを書き換えるか、ノードの間隔、閉路を作るときに結ぶ相手の近さを乱数で決める（図ごとの好み）。同じ種類でも形がかなり違う。

## 決定

`--grow` で生成した図を学習に足す。

最初に足したのは 966 枚で、実データのない dfd・c4・arch を 258 枚ずつ、BPMAI と SchemaPile がある flow と er を 96 枚ずつにした。大きさは小 2 割・中 5 割・大 3 割、雑さは tidy と wild を 15%、sloppy と messy を 35% ずつ。1/5（207 枚）はテスト用に取り分けた。

さらに、見た目でモデルが近道を覚えないよう（shortcut learning）、図ごとの好みに描き方も加えた。今の学習データで種類と結び付いている見た目（dfd のプロセスは円、c4 は境界の箱）は、生成器と元のデータの描き方の決まりで、エージェントは別の描き方もするからだ。

- ノードの役割（フローの手順、DFD のプロセスやストア、C4 のアプリやデータベースなど）ごとに描く形を決める。
- 図ごとに、記法をどれだけ守るか（0〜1、多くはかなり守り、少しは守らない）を決める。守らない図ほど、全部を箱にする、全部を円にする、ノードごとに混ぜる、のどれかになりやすく、一部の役割を逆の形にする（プロセスが箱でストアが円、など）。表は形を変えない。
- 入れ子は、c4 と arch で、内側の箱を作る割合を 3 分の 1 から 3 倍まで変え、4 分の 1 の図は箱を描かない。

記録 v5 は、この描き方の図で、種類ごとに 400 枚ずつ取った。

## 結果

上位 3 件の 2 択（docs/adr/screen-as-top-3-yes-no.md）を、v3 の学習用の図だけ、`--grow` の図の半分を足したもの、すべてを足したもので学習し、同じ図で比べた（nicevg-lab の `learn/grown.py`）。表の 3 つの数は、上位 16 件に本来の手が入る割合 / 最良の改善に届く割合 / 上位 32 件に入る割合。「差」は v3 だけで学んだモデルとの差（ポイント）で、「確か」は図を選び直して出した 95% の幅が 0 をまたがないもの:

| 測った図 | v3 だけ | 半分を足す | すべて足す |
|---|---|---|---|
| v3 のテスト用（578 図） | 72.0 / 88.5 / 83.4% | 差 -0.1 / -0.2 / -0.1 | 差 -0.2 / -0.1 / -0.6 |
| リポジトリの例（6 図） | 58.3 / 79.1 / 66.7% | 差 +1.4 / +2.4（確か） / -0.7 | 差 +3.5 / +3.2（確か） / +8.3（確か） |
| `--grow` の図のテスト用（207 図、参考） | 59.9 / 80.7 / 72.7% | 差 +4.0 / +2.5 / +3.1（確か） | 差 +4.8 / +3.1 / +3.8（確か） |

得たもの:

- 今までの図（v3 のテスト用）は悪くならない。BPMAI、型で作った図、SchemaPile のどれでも差はぶれの中。
- リポジトリの例で良くなり、量を増やすほど伸びる。
- `--grow` の図は、v3 だけで学んだモデルには難しい（上位 16 件 59.9% と、v3 のテスト用の 72.0% より低い）。今までのデータにない形を持っていて、すべて足すと、`--grow` の図のテスト用で上位 16 件が 4.8 ポイント上がる。

失ったもの:

- 記録が重くなる。大きな図が多く、966 枚の記録に 94 分かかり、候補は約 84 万件増えた。
- 良くなるという証拠が、合成の図と 6 図の例に頼っている。6 図は約 50 ステップしかなく、図を選び直して出した 95% の幅もあてにしにくい。エージェントが描いた本物の下書きを、確かめる用にもっと集めたい。
