# Windows では、宣言のフォントにないタイ語とグルジア語を、Chrome と同じフォントで測る

のちに [名前で指定したフォントで描けない部分の幅は、字とスクリプトから見積もる](estimate-widths-without-a-font.md) に置き換えた。
## 状況

宣言のフォントにない文字は、かなと漢字を除き、マシンのフォールバックが選ぶフォントで測る（[宣言のフォントにないかなと漢字は、フォールバックのフォントではなく桁数で測る](kana-and-han-by-columns.md)）。読み手のブラウザーが別のフォントを選ぶと、幅が合わない。文字がはみ出すことは問題になる。広く見積もりすぎることも、過剰であれば避けたい。

このマシン（Windows 11 25H2）で、fontique が見本の文字列を持つ 161 のスクリプトのうち、Arial になく、フォールバックのフォントがある 149 のスクリプトを `sans-serif` で測った。headless Chrome 157（en-US）が描く幅と比べると、145 のスクリプトで一致した。Chrome が Windows のフォールバックと同じフォントで描くためである。一致しなかったのは次の 4 つだった。

| スクリプト | Windows のフォールバック | Chrome の幅と一致するフォント | nicevg の幅と Chrome の幅の差 |
|---|---|---|---|
| タイ語 | Leelawadee UI | Tahoma | よく使う 40 語で −16〜−4% |
| グルジア語 | Segoe UI | Sylfaen | よく使う 8 語で +10〜+12%、古い大文字（アソムタヴルリ）の 1 語で −11% |
| コプト文字 | Segoe UI | Segoe UI Historic | 見本で −1.8% |
| モンゴル文字 | Mongolian Baiti | — | 見本で +12%、1 語で 0% |

Chromium は Windows で、スクリプトごとの固定のリストのうち、マシンにある最初のフォントで描く（Blink の `font_fallback_win.cc`）。タイ語のリストの先頭は Tahoma、グルジア語のリストの先頭は Sylfaen で、上の表と一致する。

コプト文字のずれは、コプト文字のブロック（U+2C80〜）を Windows のフォールバックの Segoe UI が持たず、どのフォントにもない文字として桁数で測られることによる。

## 決定

- Windows では、タイ語とグルジア語（スクリプト `Thai`、`Geor`）のフォールバックの先頭に、Chromium のリストの先頭のフォント（Tahoma、Sylfaen）を置く。システムのフォールバックが選ぶフォントは、その後ろに残す。
- ほかのスクリプトと、ほかの OS は変えない。

## 結果

nicevg の幅と、このマシンの headless Chrome 157 が描く幅の差:

| テキスト | 変更前 | 変更後 |
|---|---|---|
| タイ語のよく使う 40 語 | −16〜−4% | −0.1〜0% |
| タイ数字 ๐〜๙ | — | 0% |
| グルジア語のよく使う 8 語 | +10〜+12% | 0% |
| グルジア語の大文字（ムタヴルリ 3 語、アソムタヴルリ 1 語） | 0%、−11% | 0% |

27 種類のテキストを 6 つの `font-family` で測った比較では、差の絶対値の合計が 99.51px から 29.43px になった。かな、漢字、全角の句読点、①、※ を含むテキストの幅は変わらない。

得たもの:

- Windows の Chrome で、タイ語とグルジア語の幅が一致する。はみ出しも、広く見積もりすぎることもなくなった。
- 一致していた 145 のスクリプトの幅は変わらない。

失ったもの:

- Windows の Chromium の選び方を写したので、Chromium がリストを変えたら追従が要る。Windows 以外の OS とほかのブラウザーには、合う保証がない。
- コプト文字のブロックの文字は、桁数で測られ、Chrome より狭い（見本で −1.8%、「ⲁⲛⲟⲕ」で −10%）。
- モンゴル文字は、見本で Chrome より 12% 広く測られる。

## 採らなかった案

- フォールバックのフォントで描くテキストを、一律にその幅の 1.2 倍と見積もる: タイ語は Chrome の幅以上になるが、一致していた 145 のスクリプトも 20% 広く、グルジア語は 32〜35% 広く測られる。宣言のフォントを引いて比べる処理も要る。
- スクリプトごとに倍率を持つ（タイ語だけ 1.2 倍）: 倍率を当てる部分を見分けるため、ランのフォントが宣言のフォントか調べる処理と、文字の範囲でスクリプトを決める処理が要る。タイ語は Chrome より 0.5〜15% 広く測られ、タイ数字の多いテキストは覆えない（文字ごとの比は最大 1.321）。Chrome と同じフォントで測れば、少ないコードで一致する。
- スクリプトごとに、マシンにあるフォントのうち最も広いフォントで測る: 文字からスクリプトを求める処理と、スクリプトごとにすべてのフォントを調べる処理が要る。装飾用の広いフォントがあれば、それで測ることになる。
- コプト文字とモンゴル文字も直す: 図のラベルに使われることがまれで、ずれも小さいか、広く測る向きである。
