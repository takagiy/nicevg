# テストリスト — nicevg doc（文書に埋め込んだ図）

`nicevg doc <files…>` は、markdown の `<!-- nicevg … -->` コメントに書いた図のスクリプトを、サンドボックスで実行して図を描き、出力先へ書く。結果は stdout の JSON（`changedFiles`・`failures`・`remainingIssues`）で返す。

## ブロックと出力

- [x] 見出し行に `.svg` のパスがあるブロックを描くと、markdown からの相対パスに SVG を書き、ブロック直後の `<!-- nicevg:output -->` と `<!-- /nicevg:output -->` の間に画像リンクを書く
- [x] 見出し行にパスがないブロックは、印の間に SVG を空行なしで埋め込む
- [x] 見出し行のパスの後ろの文字列が代替テキストになり、なければファイル名から作る
- [x] 空白を含むパスは JSON の文字列として書け、画像リンクは山かっこで囲む
- [x] 印の外の markdown は 1 文字も変わらない
- [x] 描き直しても変わらない図は、SVG も markdown も書き直さず、`changedFiles` は空になる
- [x] コードブロックやインラインコードの中の `<!-- nicevg` は描かない
- [x] リストや引用の中のブロックは、トップレベルに置くよう求める失敗になる
- [x] 印が片方しかないブロックは失敗になり、markdown を書き換えない

## 図のスクリプト

- [x] README と同じく `nicevg` と `nicevg/style/simple` を import して `render` を 1 回呼ぶ TS のブロックが描ける
- [x] `render` を呼ばないブロックと、2 回呼ぶブロックは失敗になる
- [x] `render` の戻り値の `write`・`report`・`toString` を使うと失敗になる
- [x] スクリプトの例外は、markdown の行と列を指すスタックとともに `error` に入る
- [x] 構文エラーは、その場所とともに失敗になる
- [x] `enum` のように型を消すだけでは JS にならない構文は失敗になる
- [x] `<!-- nicevg-module 名前` のブロックを `#名前` で import できる
- [x] 同じ名前の `nicevg-module` が 2 つあると、どちらも失敗になる（片方が黙って隠れない）
- [x] サンドボックスのディレクトリの中の `.ts`・`.js` を相対パスで import できる
- [x] `node:`・URL・パッケージ名の import、ディレクトリの外や `.git`・`node_modules` の中のファイル、`.ts`・`.js` 以外のファイルの import は失敗になる
- [x] スクリプトからは `process`・`require`・`fetch` が見えない
- [x] `console.log` の出力は、ブロックの場所を付けて stderr に出る
- [x] 1 ブロックの `console` の出力は 1 MB で切り、切ったことを 1 行で知らせる
- [x] `Date` と `Math.random` は使える

## 上限

- [x] 時間の上限を超えたスクリプト（無限ループ）は失敗になり、ほかのブロックは描かれる
- [x] メモリの上限を超えたスクリプトは失敗になる
- [x] 時間の上限を超えた配置は、子プロセスを止めて失敗になる
- [x] 大きさの上限を超えた SVG は書かずに失敗になる
- [x] 配置の子プロセスが自分で止まったときは、その図だけが失敗になり、ほかの図の処理と JSON の出力は続く

## 出力先

- [x] 出力先が、サンドボックスのディレクトリの外、`.git` の中（大文字小文字を問わない）、シンボリックリンクで外へ出る場所、絶対パスのときは、失敗になる（`.svg` で終わらない最初の語は出力先ではなく説明として読み、図を埋め込む）
- [x] 同じ出力先に書く 2 つのブロックは、どちらも失敗になる

## 結果と終了コード

- [x] stdout には `changedFiles`・`failures`・`remainingIssues` の JSON だけが出て、パスはサンドボックスのディレクトリからの相対で `/` 区切りになる
- [x] 描けた図に残った問題は、`remainingIssues` に `code` と `message` で入る
- [x] 配置のときに見つかった sketch の不正は、`render` を呼んだ場所とともに失敗になる
- [x] 失敗した図がなければ終了コードは 0、あれば 2 になる
- [x] `--dry-run` は何も書かず、書き換える予定のファイルを `changedFiles` に返す
- [x] サンドボックスのディレクトリは、既定で渡したファイルの git のルートになる
- [x] 別々の git リポジトリのファイルを渡すと、何も描かずに終了コード 2 で終わる
- [x] git の外のファイルを `--sandbox-dir` なしで渡すと、終了コード 2 で終わる
- [x] `.md` 以外のファイルを渡すと、終了コード 2 で終わる
