# テストリスト — 子に合わせて広がる親

docs/adr/parents-fit-their-children.md の決定を、1 項目ずつ実テストにする。

## 検査（`tests/inspection.rs`）

- [x] 子が親の枠から出ているか、枠との余白が 12px に足りないと、子と親を示す問題 `node-outside-parent` になる
- [x] 余白を保って枠の中にある子は、報告されない
- [x] 親のグループか枠の要素の `data-padding` が余白になり、両方にあればグループの値を使う
- [x] 親自身の文字に重なる子は、子と親を示す問題 `parent-text-overlap` になり、重ならない子は報告されない

## 修正（`tests/fix.rs`）

- [x] `<rect>` の親からはみ出した子は、修正すると親の枠がはみ出した向きに広がって余白ごと収まり、ほかの辺は動かない
- [x] 入れ子の親は、内側の親が広がって外側の親からはみ出すと、外側の親も広がる
- [x] `data-custom` の親は広げず、問題として残る
- [x] 親の文字に重なる子は、修正すると文字から余白の分だけ離れる、下か右の近いほうへ動き、親の上の辺は動かない
- [x] 広がった親が兄弟のノードに重なるか 20px 未満に近づくと、ほかのノードどうしと同じく、そのノードが離される

## 配置の調整（`tests/arrange.rs`）

- [x] 子を親の外寄りへ動かすと線がまっすぐになる図では、配置の調整が子を動かし、親が広がって子を囲む
- [x] 親が広がると隣のノードに近づきすぎる移動は採らない

## ネイティブの Sketch（`tests/sketch.rs`）

- [x] 大きさを書かない矩形の親は、子を囲む範囲に余白を足した枠になり、修正するとタイトルに重なる子がタイトルの下へ動く
- [x] 位置も書かない親は、位置も子から決まる
- [x] 書いた位置と大きさは最小の枠として残り、子がはみ出す向きにだけ広がる
- [x] `padding` が親の余白になる
- [x] 子を持たないノードで `x`・`y` を省くと、そのノードを示すエラーになる

## TypeScript の Sketch（`bindings/js/test/bun/`）

- [x] 親のスタイルは、子を囲む大きさと決まった大きさで 2 回呼ばれ、描いた図の親は決まった大きさで描かれる
- [x] 親に書いた `width`・`height` は、仮の呼び出しにそのまま渡る
- [x] 入れ子の親は内側から順に仮に描かれ、外側の親は内側の親の仮の絵を囲む
- [x] 親のスタイルが書いた文字には、子が重ならない
- [x] 親のスタイルが枠の中央に書いた文字は、親の枠を広げない
- [x] 仮の絵が渡した大きさより大きければ、それが親の最小の大きさになる
- [x] 親のスタイルが付けたポートへ線を引ける
- [x] 決まった大きさで描いた文字が仮の絵と違う位置にあると、レイアウトを 1 回やり直し、その文字にも子が重ならない
- [x] やり直しても絵が前提と違えば、修正をかけ、どの親の何が違うかを問題として報告する
- [x] 親のスタイルが例外を投げると、1 回目でも 2 回目でも、その親を示す例外になる
- [x] `nicevg doc` の図のスクリプトでも、親が子に合わせて描かれる
- [x] `labelPosition: "top-left"` の `box` は、ラベルを左上から `padding` の距離に置き、枠に `data-padding` を書く。`padding` を書かなければ 12px。ラベルが子より広ければ、ラベルが収まるまで枠を広げる
